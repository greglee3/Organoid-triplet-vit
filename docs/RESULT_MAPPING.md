# Manuscript result mapping

Table numbers refer to the CSE-reference draft before final renumbering.

| Manuscript item | Included reference | Regeneration workflow |
|---|---|---|
| Table 1, present-study rows | `reference_results/public_test_ensemble.json` | Workflow 07, then 11 |
| Figure 2, confusion matrices | Same JSON, `models.*.confusion_matrix` | `scripts/report_results.py` |
| Figure 3, ROC curves | Requires generated probability arrays | `scripts/plot_roc.py` after 07 and 11 |
| Table 3, multi-seed OOF | `reference_results/multiseed_oof.json` | Workflow 14 |
| Table 4, matched public test | `reference_results/public_test_vit.json` | Workflow 07 |

Workflow directories are under `05_final_tuning/PROFESSOR_FEEDBACK/`.
07 is `07_locked_triplet_final_test`; 11 is
`11_locked_triplet_notebook_eff_final_test`; 14 is
`14_ce_vs_triplet_confirmatory`.

The reference JSON files are copied from historical server outputs, not
recomputed training results. The per-seed OOF CSV and per-image prediction
arrays are generated by the workflows but are not shipped here. Table 1's
Asano et al. rows are literature comparisons, not outputs of these scripts.
Any derived literature metrics require an explicit calculation note.
